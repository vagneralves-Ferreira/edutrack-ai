\# Proposal: Create Academic Tasks Table



\## Why



O EduTrack AI precisa de uma tabela central de tarefas acadêmicas para

organizar atividades, prazos e progresso das disciplinas da faculdade.

Atualmente não existe uma estrutura consolidada para armazenar e consultar

essas tarefas, o que dificulta o acompanhamento do desempenho acadêmico.



\## What Changes



\- Criação da tabela `academic\_tasks` com os campos essenciais (disciplina,

&nbsp; título, descrição, data de entrega, status e prioridade).

\- Scripts de apoio para CRUD de disciplinas, busca de tarefas e cálculo de

&nbsp; progresso.

\- Geração de relatório em PDF a partir das tarefas cadastradas.



\## Impact



\- Adiciona novos scripts na pasta `scripts/` e a tabela em `tables/`.

\- Não altera a estrutura das funcionalidades já existentes.
